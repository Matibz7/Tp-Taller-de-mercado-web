# Tp-Taller-de-mercado-web
Proyecto "Refugio Huellitas"

*Refugio Huellitas* es una pagina web desarrollada con html,css,javasript y bootstrap pensada para dar visibilidad a los animales rescatados de la zona de Hurlingham y alrededores, facilitando el proceso de adopción, la gestión de hogares de tránsito y la concientización sobre la castración masiva.
